Instala la biblioteca cryptography:

pip install cryptography

Guarda el código en un archivo llamado json_crypto.py

python json_crypto.py

Este código:
Utiliza la biblioteca cryptography para el cifrado
Genera una clave única para cada instancia
Convierte los datos JSON a bytes y viceversa
Usa base64 para facilitar el almacenamiento de datos cifrados
Mantiene la estructura JSON original después del descifrado
